REFERRAL LINK SETUP

The bot now supports an admin-configurable Bot Public Link.

Admin -> Settings -> 🔗 Set Bot Public Link

Accepted examples:
  https://t.me/YourBotUsername
  @YourBotUsername

The saved link is used for:
- My Account referral link
- Referral statistics page
- Welcome/start referral link
- Referral inline button

If the setting is not configured, the bot tries to auto-detect its Telegram username with get_me().
